MU's own structural similarity metric places cyclic

The linearity assumption in Limitation 1 of the

This is a new finding. It was not identified in the
preprint. It means:

1. The within-category entropy correction for the

   **systematically different** for cyclic vs
   linear ethers, for geometric reasons independent
   of donor number.

2. The mixing approximation used for Candidates 1

   linear DN interpolation) spans a genuine
   structural discontinuity in chemical space —
   not a smooth continuum.

3. The linearity test requires a **separate search
   anchored to cyclic ethers** to be completed.
   The DME-anchored search cannot reach cyclic
   ether space.
