### The Structural Separation Confirmed

primary coordination classes are structurally
separated in MU's similarity space.

The **convergence zone** — DME and diglyme appearing
in the DOL search — marks the boundary between
the two classes. This boundary is real and
quantifiable.

### The Linearity Test Status

The linearity assumption in Limitation 1 requires
that 2-MeTHF sits on the DME–DEE linear ether axis
by donor number. The combined search results show:

MU flagged a data quality issue for DEC:

```
Registered mp: -43°C (all literature since 1921)
Corrected mp:  -74.3°C (DOI 10.1149/1.1353568, 2001)
Source of error: Single uncorrected entry from 1921
```

**Framework implication:** DEC is liquid at -74.3°C,
not -43°C. For the Arctic optimum search (Search 3),
DEC should not be excluded on melting point grounds.
Its coordination behavior (carbonate, Regime 3) still
excludes it from the Arctic ether candidate list,
but the thermal operating range of carbonate-containing
systems is wider than commonly assumed.

This is a data quality correction to the published
record, surfaced by MU. It should be noted in the
repository.
