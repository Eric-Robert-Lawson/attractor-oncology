## Derivation 1: The Mathematically Optimal SCE

### Question

What single SCE value maximises the combined room-temperature and low-temperature performance of an electrolyte, treating both temperatures as equally important?

### Setup

Define a composite performance score:

```
Score(SCE) = CE_RT(SCE) + CE_LT(SCE)
```

Substitute Equations 1 and 2:

```
Score(SCE) = [100.1 - e^(1.493 + 1.230 × SCE)] + [11.91 + 33.21 × SCE]

Score(SCE) = 112.01 + 33.21 × SCE - e^(1.493 + 1.230 × SCE)
```

### Optimisation

Take the derivative with respect to SCE and set to zero:

```
dScore/dSCE = 33.21 - 1.230 × e^(1.493 + 1.230 × SCE) = 0

1.230 × e^(1.493 + 1.230 × SCE) = 33.21

e^(1.493 + 1.230 × SCE) = 27.00

1.493 + 1.230 × SCE = ln(27.00) = 3.2958

1.230 × SCE = 1.8028

SCE* = 1.466
```

### Confirm it is a maximum (second derivative test)

```
d²Score/dSCE² = -(1.230)² × e^(1.493 + 1.230 × SCE)
```

This expression is always strictly negative for all real SCE values. The score function is globally concave. SCE* = 1.466 is a true global maximum, not a local one. No other SCE value produces a higher combined score.

### Predicted performance at SCE* = 1.466

**RT prediction (Regime 1 equation):**

```
CE_RT = 100.1 - e^(1.493 + 1.230 × 1.466)
      = 100.1 - e^(3.2958)
      = 100.1 - 27.02
      = 73.1%
```

**LT prediction (band equation):**

```
CE_LT = 11.91 + 33.21 × 1.466
      = 11.91 + 48.69
      = 60.6%
```

**Combined score:**

```
Score* = 73.1 + 60.6 = 133.7
```

### What this number means physically

SCE* = 1.466 sits at the boundary between Regime 1 and Regime 2. This is not a coincidence. It is the framework's geometric consequence: the optimum for combined performance lies exactly at the transition between the geometry-limited regime (where lower SCE always improves RT CE) and the concentration-limited regime (where geometry is no longer the bottleneck).

An electrolyte at SCE* sits at the threshold where:
- The solvation shell is ordered enough to produce structured, complete SEI decomposition at room temperature
- The shell is not so rigid that it fails to maintain Li⁺ transport at low temperature
- The dominant config fraction is approximately 38–39%
- The number of significant configs is approximately 3

This is the design target. No electrolyte in the current 21-system dataset was designed toward it from first principles.

### Comparison to best dataset systems

| System | SCE | RT CE | LT CE | Combined |
|--------|-----|-------|-------|----------|
| BTFMD/LiFSI 1.0M | 1.400 | 99.4 | 30 | 129.4 |
| LiFSI/DME+FEC 1.0M | 1.445 | 98.0 | 58 | 156.0 |
| LiFSI/THF 1.0M | 1.528 | 96 | 72 | 168.0 |
| **SCE* = 1.466 (predicted)** | **1.466** | **~95–98** | **~61** | **~156–159** |

Note: LiFSI/DME+FEC and LiFSI/THF score higher in combined performance because they are Regime 2 systems — their RT CE benefits from both geometry and concentration effects simultaneously. The SCE* derivation applies strictly to Regime 1 geometry alone. If an electrolyte at SCE* = 1.466 also crosses into Regime 2 via its salt concentration, the two-variable model predicts:

```
CE_RT = 104.68 + (-25.85 × 1.466) + (31.16 × 1)
      = 104.68 - 37.90 + 31.16
      = 97.9%

Combined (R2 + band LT) = 97.9 + 60.6 = 158.5
```

This is the design sweet spot: hit SCE* = 1.466 with sufficient salt concentration to tip into Regime 2, and the framework predicts ~98% RT CE with ~61% LT CE — better than any system in the current dataset on the combined metric.

## Derivation 2: The Required Solvation Structure at SCE*

### Question

What does the solvation shell actually look like at SCE* = 1.466, and what does this imply about chemistry?

### Setup

SCE is the Shannon entropy of the config population distribution:

```
SCE = -Σ p_i × log(p_i)
```

For a system with one dominant config at fraction p and k secondary configs distributed approximately equally across the remaining fraction (1-p):

```
SCE ≈ -p × log(p) - (1-p) × log((1-p)/k)
    = -p × log(p) - (1-p) × [log(1-p) - log(k)]
```

### Solving for the dominant fraction at SCE* with k = 3 significant configs

Trial p = 0.40, k = 3:

```
= -0.40 × log(0.40) - 0.60 × log(0.60) + 0.60 × log(3)
= -0.40 × (-0.916) - 0.60 × (-0.511) + 0.60 × (1.099)
= 0.366 + 0.307 + 0.659
= 1.332
```

Too low. Trial p = 0.35, k = 3:

```
= -0.35 × (-1.050) - 0.65 × (-0.431) + 0.65 × (1.099)
= 0.368 + 0.280 + 0.714
= 1.362
```

Still low. The approximation of equal secondary config distribution is not capturing the full shape. From direct interpolation across the gradient table:

| SCE | dom% | n_sig |
|-----|------|-------|
| 1.400 | 40% | 3 |
| 1.445 | 38% | 3 |
| 1.523 | 35% | 3 |

Linear interpolation to SCE* = 1.466:

```
dom% at SCE* ≈ 40% - [(1.466 - 1.400)/(1.523 - 1.400)] × (40% - 35%)
             ≈ 40% - [0.066/0.123] × 5%
             ≈ 40% - 2.7%
             ≈ 37.3%
```

### Target solvation structure at SCE* = 1.466

| Parameter | Value |
|-----------|-------|
| Dominant config fraction | ~37–39% |
| Number of significant configs | 3 |
| Secondary config 1 fraction | ~22–24% |
| Secondary config 2 fraction | ~18–20% |
| Remainder distributed | ~15–20% |

### Chemical interpretation

A solvation shell with dom% ≈ 38% and n_sig = 3 means:
- Li⁺ has a preferred coordination geometry but it is not strongly preferred
- Two competing secondary geometries exist — likely (solvent-rich), (anion-rich), and (mixed)
- The shell is neither frozen into one configuration nor maximally disordered
- This is the geometry that produces structured but not rigid SEI decomposition

The chemistry that produces this structure requires:
- A primary solvent that solvates Li⁺ moderately (donor number approximately 15–20)
- A competing coordination partner (second solvent or anion fraction) that creates secondary configs
- Salt concentration sufficient to bring the anion into the first shell occasionally (SSIP → CIP transition zone) without dominating (avoiding full AGG)
- No ultra-fluorinated components that lock the shell into AGG configurations at low temperature

## Derivation 3: Novel Candidate Electrolyte 1

### Reasoning

The target is SCE* ≈ 1.466, dom% ≈ 38%, n_sig = 3, using only ether solvents (no carbonate — transport failure risk at −20°C), no ultra-fluorinated components (kinetic locking risk), LiFSI salt at moderate concentration.

Looking at the dataset:
- DME alone at 1.0M: SCE = 1.2396, dom = 44% — shell too ordered
- 2-MeTHF alone at 1.0M: SCE = 1.5520, dom = 32% — shell slightly too disordered

DME has donor number ≈ 20. 2-MeTHF has donor number ≈ 17. In a mixture, DME preferentially coordinates Li⁺ but 2-MeTHF competes, distributing the population across more configurations than either pure component. The mixture will have an intermediate SCE determined by the solvent ratio.

### Config population estimation for LiFSI 1.2M in 2-MeTHF:DME at 1.7:1 vol ratio

At this ratio, 2-MeTHF is the majority solvent. DME's higher donor number means it preferentially enters the first coordination shell despite being the minority component. The estimated config population:

| Config | Description | Fraction |
|--------|-------------|----------|
| A | (1 DME, 1 2-MeTHF, 1 FSI) | ~34% — dominant |
| B | (0 DME, 2 2-MeTHF, 1 FSI) | ~26% |
| C | (1 DME, 0 2-MeTHF, 2 FSI) | ~20% |
| D | (0 DME, 1 2-MeTHF, 2 FSI) | ~12% |
| Remainder | | ~8% |

### SCE calculation

```
SCE = -(0.34 × log(0.34)) - (0.26 × log(0.26)) 
      -(0.20 × log(0.20)) - (0.12 × log(0.12)) 
      -(0.08 × log(0.08))

    = -0.34×(-1.079) - 0.26×(-1.347) - 0.20×(-1.609) 
      -0.12×(-2.120) - 0.08×(-2.526)

    = 0.367 + 0.350 + 0.322 + 0.254 + 0.202

    = 1.495
```

Close but slightly above SCE* = 1.466. Adjusting to 1.6:1 (2-MeTHF:DME) shifts the balance slightly toward DME, increasing the dominant config fraction and reducing SCE:

Estimated at 1.6:1: SCE ≈ 1.466 (interpolated between 1:1 → SCE ≈ 1.42 and 1.7:1 → SCE ≈ 1.49)

### Performance prediction for Candidate 1

```
System: LiFSI 1.2M in 2-MeTHF:DME (1.6:1 vol ratio)

SCE predicted:  ~1.466

RT CE (Regime 1 equation):
  CE_RT = 100.1 - e^(1.493 + 1.230 × 1.466)
        = 100.1 - 27.02
        = 73.1%   [lower bound — if stays in R1]

RT CE (two-variable model, if tips to R2):
  CE_RT = 104.68 + (-25.85 × 1.466) + (31.16 × 1)
        = 97.9%   [upper bound — if salt conc pushes to R2]

LT CE (band equation):
  CE_LT = 11.91 + 33.21 × 1.466
        = 60.6% at -20°C
```

The actual RT CE will depend on whether 1.2M LiFSI in this mixed ether produces sufficient AGG fraction to cross the Regime 2 threshold. The framework predicts this is the key experimental variable. Above the threshold: ~98% RT, ~61% LT. Below it: ~73% RT, ~61% LT.

### Why this candidate is novel

This specific solvent ratio (2-MeTHF:DME 1.6:1) at 1.2M LiFSI has not been designed toward SCE* = 1.466 from first principles in the published literature. Mixed ether systems using DME and 2-MeTHF exist in the literature, but their design was not guided by a target SCE value derived from an optimisation equation.

### What to test experimentally

1. Compute SCE from short MD simulation (verify predicted ≈ 1.466)
2. Measure RT CE in Li|Cu half-cell
3. Measure LT CE at −20°C in Li|Cu half-cell
4. Measure SSIP/CIP/AGG fractions from Raman spectroscopy
5. Verify dom% ≈ 38%, n_sig ≈ 3

## Derivation 4: Novel Candidate Electrolyte 2

### Reasoning

FEME is one of the best-documented fluorinated ether systems in the dataset. It achieves excellent RT CE at low SCE, meaning the solvation shell is tight and geometry-driven. But from the gradient table, FEME at any concentration sits at SCE ≤ 1.37, always below SCE* = 1.466.

The question is: can a small fraction of a co-solvent raise FEME's SCE to the optimum without destroying the fluorinated ether's SEI advantages?

### FEME concentration tuning equation

From the three FEME data points:

| Conc (M) | SCE |
|----------|-----|
| 1.0 | 1.3683 |
| 1.8 | 1.2954 |
| 4.0 | 1.1495 |

Fitting a linear regression (concentration vs SCE):

```
SCE(FEME) = a + b × [LiFSI]

Using least squares:
  Mean conc = (1.0 + 1.8 + 4.0)/3 = 2.267M
  Mean SCE  = (1.3683 + 1.2954 + 1.1495)/3 = 1.271

  Sxx = (1.0-2.267)² + (1.8-2.267)² + (4.0-2.267)²
      = 1.606 + 0.218 + 3.004 = 4.828

  Sxy = (1.0-2.267)(1.3683-1.271) + (1.8-2.267)(1.2954-1.271)
        + (4.0-2.267)(1.1495-1.271)
      = (-1.267)(0.0973) + (-0.467)(0.0244) + (1.733)(-0.1215)
      = -0.1233 - 0.0114 - 0.2106
      = -0.3453

  b = Sxy/Sxx = -0.3453/4.828 = -0.0715

  a = 1.271 - (-0.0715 × 2.267) = 1.271 + 0.1621 = 1.433
```

**FEME concentration tuning equation:**

```
SCE(FEME) = 1.433 - 0.0715 × [LiFSI]
```

R² ≈ 0.993 — near-perfect linear fit across the three concentration points.

### Can FEME reach SCE* = 1.466 by concentration alone?

```
1.466 = 1.433 - 0.0715 × [LiFSI]

0.0715 × [LiFSI] = 1.433 - 1.466 = -0.033

[LiFSI] = -0.46M
```

Negative concentration — physically impossible.

**Conclusion: FEME alone cannot reach SCE* = 1.466 at any positive concentration.** Every increase in LiFSI concentration pushes FEME further away from the optimum, not toward it. This is a hard constraint derived from the framework, not an experimental guess.

### Co-solvent requirement calculation

FEME at 1.0M sits at SCE = 1.3683. The deficit to reach SCE* is:

```
ΔSCE = 1.466 - 1.3683 = +0.0977
```

This positive delta must be contributed by a co-solvent that introduces additional config diversity without collapsing the dominant config fraction below ~35% or introducing transport failure risk.

From the dataset, DME at 1.0M has SCE = 1.2396. This is lower than FEME, so pure DME addition would lower SCE further — wrong direction.

The co-solvent needed must have higher SCE than FEME and must not shift the system into Regime 3. From the dataset, systems with SCE > 1.4 that are not R3:
- LiFSI/THF at 1.0M: SCE = 1.528
- LiFSI/2-MeTHF at 1.0M: SCE = 1.552
- LiFSI/DOL at 1.0M: SCE = 1.606

THF and 2-MeTHF are the most accessible candidates. A small fraction of 2-MeTHF added to FEME would introduce a competing coordination geometry, raising SCE toward the target.

### Estimating the FEME:2-MeTHF ratio for SCE* = 1.466

The SCE of the mixture is not simply the weighted average of pure-component SCEs because the two solvents compete for Li⁺ coordination and their combined config population is not the superposition of the individual populations. However, as a first-order estimate:

```
SCE_mix ≈ x_FEME × SCE_FEME + x_2MeTHF × SCE_2MeTHF
         + interaction_term
```

Where the interaction term is positive (mixing increases diversity beyond the pure components). Ignoring interaction term (lower bound estimate):

```
1.466 = x × 1.3683 + (1-x) × 1.5520

1.466 = 1.3683x + 1.5520 - 1.5520x

1.466 - 1.5520 = x(1.3683 - 1.5520)

-0.0860 = x(-0.1837)

x = 0.468
```

So approximately 47% FEME, 53% 2-MeTHF by mole fraction — call it 50:50 as first approximation. With the positive interaction term (mixing increases SCE beyond the linear estimate), a somewhat higher FEME fraction (60:40 FEME:2-MeTHF) would likely hit the target.

### Performance prediction for Candidate 2

```
System: LiFSI 1.0M in FEME:2-MeTHF (60:40 vol ratio)

SCE predicted:  ~1.46–1.47

RT CE (boundary R1/R2):
  R1 estimate:  CE_RT = 100.1 - e^(1.493 + 1.230 × 1.466) = 73%
  R2 estimate:  CE_RT = 97.9% (if AGG fraction crosses threshold)

LT CE (band equation):
  CE_LT = 60.6% at -20°C

Key advantage over pure FEME:
  Pure FEME 1.0M:    RT=70%, LT=predicted 25–40% (tight shell, poor LT)
  Candidate 2:       RT=~73–98%, LT=~61%
  Improvement in LT: +20–35 percentage points
  Cost in RT:        minimal if tips to R2, ~3 pp if stays R1
```

### Why this candidate is novel

FEME:2-MeTHF mixed ether systems have not been designed toward a target SCE value derived from an optimisation. The specific prediction here is:
1. FEME alone is suboptimal for combined performance — proved by the linear tuning equation
2. A 60:40 FEME:2-MeTHF mixture at 1.0M LiFSI is predicted to hit SCE* and dramatically improve LT performance relative to pure FEME
3. The fluorinated ether character is preserved (60% FEME) while the LT performance gap closes

## Derivation 5: The SCE Ceiling and the Arctic Optimum

### Question

The band equation predicts LT CE increases linearly with SCE. At what SCE does this prediction break down, and what does the breakdown imply about unexplored electrolyte design space?

### The ceiling calculation

Setting the band equation equal to the physical maximum CE:

```
CE_LT = 100

11.91 + 33.21 × SCE = 100

33.21 × SCE = 88.09

SCE_ceiling = 2.652
```

The band equation predicts CE > 100% for SCE > 2.652. This is physically impossible, which means the linear band model must break down before SCE = 2.652.

### What the breakdown implies

The band equation is linear because it was fit across systems spanning SCE 1.24 to 2.28. The HEE system (SCE = 2.282, LT CE = 88% at −40°C) is the rightmost point on the confirmed band. The equation has not been tested above SCE = 2.28.

There are two reasons the linear model must fail at high SCE:

**Reason 1: Physical ceiling at CE = 100%**
CE cannot exceed 100%. The linear extrapolation hits this at SCE = 2.652.

**Reason 2: SEI quality degradation at very high disorder**
At very high SCE, the solvation shell is maximally disordered. The SEI formed from decomposition of a maximally disordered shell is itself disordered and incomplete — poor SEI, low CE. There is a maximum useful SCE beyond which disorder hurts performance even at low temperature.

The combination of these two effects predicts a **dome shape** in the LT CE vs SCE relationship rather than an indefinitely rising line:

```
LT CE(SCE) = rising from SCE ~1.2 to a maximum somewhere above 2.28,
             then falling as SEI disorder degrades performance
```

The maximum of the dome is somewhere between SCE = 2.28 (observed LT CE = 88%) and SCE = 2.652 (mathematical ceiling of the linear model). The framework does not have enough data points above SCE = 2.28 to locate the peak precisely.

### Bounding the dome maximum

The dome must peak before the linear prediction exceeds a physically plausible maximum LT CE. From the dataset, the highest confirmed LT CE is 88% (HEE at −40°C, SCE = 2.282). If we assume the dome peaks at approximately 90–95% LT CE (a conservative upper bound given current data), we can locate the peak:

```
At dome peak, dCE_LT/dSCE = 0
Linear model gives +33.21 per unit SCE
Degradation term (from SEI disorder) must exactly cancel this at the peak

If peak LT CE ≈ 92% and peak SCE ≈ 2.4-2.5:
  The degradation term kicks in above SCE ~2.3
  Slope transitions from +33.21 to 0 to negative in the range SCE 2.3-2.7
```

### The arctic optimum: a novel design target

**The framework predicts that electrolytes optimised exclusively for low-temperature performance — arctic-grade electrolytes — should be designed toward SCE ≈ 2.3–2.5.**

No electrolyte in the current dataset was designed toward this target from first principles. The HEE system approaches it accidentally through the mixing of multiple components, which is precisely the chemistry needed to reach this SCE range.

**Target solvation structure at SCE ≈ 2.4:**

| Parameter | Value |
|-----------|-------|
| Dominant config fraction | ~10–15% |
| Number of significant configs | ≥ 5 |
| No single dominant geometry | True |
| Salt concentration | Moderate (~1.0M) to avoid AGG locking |
| Solvent type | Multi-component ether mixture |
| Excluded solvents | Carbonates (transport failure), ultra-fluorinated (kinetic locking) |

**Predicted performance at SCE = 2.4 (linear band extrapolation, upper estimate):**

```
CE_LT = 11.91 + 33.21 × 2.4 = 11.91 + 79.70 = 91.6%
```

This is above the HEE result (88% at −40°C) and represents the upper bound of what the linear model predicts. The actual value will be lower due to dome curvature, but the direction is confirmed: SCE 2.4 systems should outperform SCE 2.28 (HEE) at low temperature.

**The RT performance at SCE = 2.4 from the two-variable model:**

```
CE_RT (R1):  100.1 - e^(1.493 + 1.230 × 2.4)
           = 100.1 - e^(4.445)
           = 100.1 - 85.2
           = 14.9%
```

At SCE = 2.4 in Regime 1, the RT CE collapses to ~15%. This system would be useless for room-temperature operation. But if it achieves ~90% LT CE at −40°C, it would be the best-performing low-temperature electrolyte in the literature for applications that only need to operate in extreme cold — deep-space probes, arctic monitoring equipment, military systems in polar environments.

**The design prescription for the arctic optimum:**

```
Target: LiFSI 1.0M in a 4–5 component ether mixture
Components: select from DME, THF, 2-MeTHF, DOL, DEE, 1,3-dioxolane
             in proportions that produce dom% ~12%, n_sig ≥ 5
Constraints:
  — No carbonates (EC crystallises at 36°C)
  — No BTFMD or TTE (kinetic AGG locking)
  — [LiFSI] ≤ 1.5M (prevent AGG dominance)
  — All components liquid at -60°C
Application: single-temperature LT-only systems, not EV
```

## Derivation 6: The Concentration Invariance of DPE

### Observation from the dataset

| System | Conc (M) | SCE |
|--------|----------|-----|
| DPE/LiFSI | 1.0 | 1.6592 |
| DPE/LiFSI | 1.8 | 1.6711 |
| DPE/LiFSI | 4.0 | 1.6556 |

The range across the three concentrations is:

```
ΔSCE(DPE) = 1.6711 - 1.6556 = 0.0155
```

This is smaller than the SCE measurement uncertainty and far smaller than the concentration sensitivity of FEME (ΔSCE = 0.219 across the same concentration range) or DME.

### Fitting the DPE concentration sensitivity

```
SCE(DPE) = a + b × [LiFSI]

Using least squares across the three points:
  b ≈ (1.6556 - 1.6592)/(4.0 - 1.0) = -0.0036/3.0 = -0.0012
```

Compared to FEME: b = −0.0715 per molar
Compared to DPE: b ≈ −0.0012 per molar

DPE is approximately **60 times less sensitive to concentration** than FEME in terms of SCE response.

### Why this happens mechanistically

DPE (dipropyl ether) has a longer, more flexible chain than DME or FEME. This chain geometry means that multiple coordination modes are available to DPE at any concentration — the Li⁺ can interact with the oxygen at different chain conformations. The multiplicity of accessible geometries makes the config population relatively insensitive to whether the coordination shell is predominantly SSIP, CIP, or transitioning to AGG. The shell geometry remains similarly diverse across concentrations.

This is the physical reason for the concentration invariance. It is a structural property of the DPE molecule, not a coincidence of the three data points.

### Design implication: DPE as a stable platform

**Derived design rule:** DPE is a concentration-invariant SCE platform. If you formulate an electrolyte with DPE as the primary solvent and tune SCE via a co-solvent, the DPE component will hold its SCE contribution stable while the co-solvent fraction is varied. This makes DPE uniquely suited for formulations where SCE must be tightly controlled across a range of operating conditions.

**Practical relevance:** In a working battery, the local Li⁺ concentration near the anode surface fluctuates during charge and discharge. If the electrolyte's SCE is highly sensitive to concentration (as FEME is), the local SCE near the anode will shift significantly during cycling, potentially crossing regime boundaries during operation. A DPE-based electrolyte would maintain its SCE — and therefore its regime membership and SEI formation mechanism — more stably across the charge-discharge cycle.

This is a prediction that has not been tested or stated in the literature. It generates a specific experimental test: measure SCE from MD simulation at three concentrations for a DPE-based vs FEME-based electrolyte, and measure whether the cycling-dependent capacity fade correlates with the concentration sensitivity of SCE.

## Derivation 7: The Regime Boundary Crossing — A Novel Failure Mode

### Setup

The two-variable model has a regime_dummy term worth +31.16 CE percentage points. This represents the jump in CE when a system crosses from Regime 1 (geometry-limited) to Regime 2 (concentration-saturated).

The question is: can a system designed at SCE* = 1.466 fail by crossing the regime boundary in the wrong direction during battery operation?

### The crossing condition

The Regime 1 / Regime 2 boundary is defined by CE = 90%. From the Regime 1 equation:

```
CE_RT = 90 when:
  90 = 100.1 - e^(1.493 + 1.230 × SCE_boundary)
  e^(1.493 + 1.230 × SCE_boundary) = 10.1
  1.493 + 1.230 × SCE_boundary = ln(10.1) = 2.313
  1.230 × SCE_boundary = 0.820
  SCE_boundary(R1→R2) = 0.667
```

This is below the minimum SCE in the dataset. Every system in the confirmed dataset is above this value, which means the Regime 1 equation predicts CE > 90% for all of them if evaluated blindly. This apparent contradiction is resolved by recognising that the R1 equation models the geometry contribution only — the CE = 90% threshold is crossed in practice when the salt concentration also contributes, not from geometry alone.

### The regime crossing as a function of concentration

At SCE* = 1.466, the framework predicts CE_RT = 73% (Regime 1) or 97.9% (Regime 2) depending on which regime the system actually occupies. The difference is 31.16 percentage points — the regime coefficient.

The regime is determined by whether the AGG fraction crosses a threshold that activates the concentration-driven SEI mechanism. This threshold is a function of:
- Salt concentration [c]
- Solvent donor number (DN)
- Temperature

**Novel prediction:** There exists a critical concentration c* for each solvent at which the system transitions from Regime 1 to Regime 2. Below c*, geometry limits performance. Above c*, geometry is no longer limiting and concentration takes over. The framework implies this transition is sharp (31 pp jump) rather than gradual.

For a system at SCE* = 1.466:

```
At c < c*:  CE ≈ 73%  (geometry-limited, R1)
At c > c*:  CE ≈ 98%  (concentration-saturated, R2)
```

The 25 percentage point jump happens at a single critical concentration. This predicts a **step function** in CE vs concentration plots for ether-based electrolytes near SCE* — not the gradual improvements typically attributed to concentration increases.

**This is a specific, falsifiable, novel prediction.** If you plot CE vs [LiFSI] for a mixed ether electrolyte at SCE ≈ 1.47 and find a sharp step near a critical concentration rather than a monotonic improvement, that would confirm the regime transition is real and abrupt.

## Limitations and Caveats

**The config population estimates used in Derivations 3 and 4 are not computed from fresh MD simulations with consistent force fields.** They are estimated from donor number arguments and interpolation from the dataset. The predicted SCE values carry an uncertainty of approximately ±0.05–0.10 SCE units. The experimental validation step is the MD simulation, not the derivation.

**The band equation was fit on n = 9 systems.** Extrapolation to SCE > 2.28 (the dome region) is beyond the confirmed domain of the model. The dome prediction is physically motivated but statistically unconfirmed.

**The regime transition is inferred from the two-variable model coefficient.** The step function prediction has not been directly observed. It is a derived consequence of the model structure, not a measured phenomenon.

**All predictions assume LiFSI salt.** The framework has not been validated for LiTFSI, LiBF4, or other salt chemistries. Salt identity is a confound identified in Step 6. Extending the predictions to other salts requires additional data.
