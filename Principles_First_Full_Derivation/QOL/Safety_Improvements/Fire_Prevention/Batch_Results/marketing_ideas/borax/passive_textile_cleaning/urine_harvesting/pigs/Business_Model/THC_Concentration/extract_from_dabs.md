```
├─ Reason: Both are relatively nonpolar
├─ Ethanol dissolves THC very effectively
├─ Result: YES, dabs will dissolve

Other cannabinoid solubility:
├─ CBD: Soluble in ethanol
├─ CBN: Soluble in ethanol
├─ Other cannabinoids: Soluble in ethanol

Terpene solubility:
├─ Terpenes: Soluble in ethanol
├─ Reason: Nonpolar compounds
├─ Result: Terpenes dissolve too

Waxes & lipids in dabs:
├─ Plant waxes: Somewhat soluble in ethanol
├─ Plant lipids: Soluble in ethanol
├─ Result: These dissolve too

══════════════════════

├─ Dabs begin contacting ethanol
```

## PART III: MODIFIED PROTOCOL FOR DABS

### 3.1 — How to Adapt Your Protocol

**Step-by-step changes:**

```
═══════════════════════════════════════════════════════════════════
MODIFIED PROTOCOL - USING DABS INSTEAD OF FLOWER
═══════════════════════════════════════════════════════════════════

STAGE 0: DETERMINE DAB AMOUNT & EQUIVALENT
═════════════════════════════════════════════════════════════════

First, you need to know:
├─ How much dabs do you have? (grams)
├─ What potency/type? (high-grade, shatter, budder, etc.)
└─ Goal: Calculate equivalent flower amount


DAB POTENCY ESTIMATES:
─────────────────────

Dab types and typical potency:

High-grade shatter/diamonds:
├─ THC content: 80-95%
├─ Quality: Excellent
├─ Recommended: Use these

Budder/wax/crumble:
├─ THC content: 60-85%
├─ Quality: Good
├─ Recommended: Use these

Live resin/fresh press:
├─ THC content: 70-85%
├─ Quality: Good (with terpenes)
├─ Recommended: Use these

Older/degraded dabs:
├─ THC content: 50-70% (some oxidation)
├─ Quality: Still usable
├─ Recommended: Use these (your case probably)

Very old/dark dabs:
├─ THC content: 40-60% (oxidized)
├─ Quality: Reduced but still effective
├─ Recommended: Still use these


EQUIVALENT FLOWER CALCULATION:
──────────────────────────────

If you have: D grams of dabs at P% potency
Convert to: Equivalent flower amount for protocol calculation

Formula: Equivalent flower = D ÷ (Potency ÷ 30)

Where:
├─ D = dab amount (grams)
├─ Potency = dab THC% (e.g., 70 for 70% THC)
└─ 30 = assumed flower potency (30%)

Examples:

5g dabs at 70% THC:
├─ Equivalent = 5 ÷ (70 ÷ 30) = 5 ÷ 2.33 = 2.15g flower equivalent
├─ Use this: 2.15g (or round to 2g) in all calculations
└─ This becomes your X value

2g dabs at 80% THC:
├─ Equivalent = 2 ÷ (80 ÷ 30) = 2 ÷ 2.67 = 0.75g flower equivalent
├─ Use this: 0.75g (or round to 1g) in all calculations
└─ This becomes your X value

3g dabs at 85% THC:
├─ Equivalent = 3 ÷ (85 ÷ 30) = 3 ÷ 2.83 = 1.06g flower equivalent
├─ Use this: 1g in all calculations
└─ This becomes your X value


MODIFIED STAGE 1: DAB DISSOLUTION (Instead of extraction)
═══════════════════════════════════════════════════════════════

SKIP: The 30-40 minute extraction process
DO: Quick dissolution instead

Materials:
├─ Dabs: D grams
├─ Everclear: (X × 12) ml [where X = equivalent flower]
├─ Container: For mixing
└─ Spoon: For stirring

Procedure:
[ ] Step 1.1: Put dabs in container
    ├─ D grams of dabs
    ├─ Can be consolidated if they're separated
    └─ Just put all dabs together

[ ] Step 1.2: Pour ethanol over dabs
    ├─ Pour E = X × 12 ml everclear
    ├─ Should cover dabs completely
    └─ Dabs will immediately start dissolving

[ ] Step 1.3: Stir/mix dabs into ethanol
    ├─ Stir for 30-60 seconds
    ├─ Dabs will break apart and dissolve
    ├─ Continue stirring until mostly dissolved
    ├─ Most should be dissolved within 2-5 minutes
    └─ Complete dissolution: 5-10 minutes

[ ] Step 1.4: Observe result
    ├─ Ethanol is now darker (golden/amber to brown)
    ├─ Dabs mostly dissolved
    ├─ Some residue might remain (that's OK)
    ├─ This is your "enriched ethanol"
    └─ Contains THC (ready for next stage)

[ ] Step 1.5: Optional - filter out residue
    ├─ If dabs were: Low-quality/degraded
    ├─ May have: Some non-dissolved material
    ├─ To filter: Use coffee filter or strainer
    ├─ Pour enriched ethanol through filter
    ├─ Residue: Caught by filter (discard)
    ├─ Ethanol: Collected and ready
    ├─ Result: Very clean enriched ethanol
    └─ Optional: Do this if dabs were really old/messy


RESULT AFTER STAGE 1:
═════════════════════

You have:
├─ Enriched ethanol (E ml, containing THC from dabs)
├─ Ready to use immediately
├─ No extraction step needed (dabs already extracted)
└─ Time saved: 30-40 minutes (huge advantage)


STAGES 2-7: PROCEED AS NORMAL
══════════════════════════════

After your dabs are dissolved:

Stage 2: Cannabis filtering
├─ SKIP THIS (no cannabis material to filter)
├─ You already have clean ethanol from dabs
├─ Just use the enriched ethanol directly
└─ Advantage: One fewer step

Stage 3: Dry powder mix preparation
├─ SAME as before
├─ Calculate: P = X ÷ 3 (where X = equivalent flower)
├─ Mix: SAP + bentonite + baking soda
└─ Continue as normal

Stage 4: Powder hydration with enriched ethanol
├─ SAME as before
├─ Use: E_hydration = X × 5 ml
├─ Mix: Powder + enriched ethanol (from dabs)
└─ Continue as normal

Stage 5: Ethanol evaporation
├─ SAME as before
├─ Spread in dish, let evaporate 6-24 hours
├─ Use fan for speed if desired
└─ Continue as normal

Stage 6: Water rehydration (when using for application)
├─ SAME as before
├─ Add water: W = X × 5 ml (recommended)
├─ Blend into aerogel
└─ Continue as normal

RESULT: Same final thermal aerogel product
└─ Just with dab-sourced THC instead of flower-sourced


TIME SAVINGS COMPARISON:
═════════════════════════

Using flower (cannabis):
├─ Stage 1: 30-40 minutes (extraction)
├─ Stage 2: 10-15 minutes (filtering)
├─ Stage 3-6: Same as below
└─ Total active time: 1.5+ hours

Using dabs:

└─ Total active time: ~45-50 minutes

Time savings: 30-45 minutes of active work (HUGE advantage)
```
