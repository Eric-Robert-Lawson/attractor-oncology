Its base is `boundary_board_states_f_p_construction.md`, whose record was brought up to date for a first attempt on 22 November 2026 (§1, item 73; §4). That file is not changed by this one. This file adds no primitive to the primitive catalog and does not touch the hard core. It is stated in general terms: no piece, material, position or engine is part of it, and the statements of the attempts are given in the same terms.

Nothing has been run. §2 is empty because no attempt has been made.

**What this file records.** Each attempt, as it was made: the code version, the baseline choices used, what was observed, and what was not observed or could not be run. A failed attempt is recorded here and not in the construction file (§1, item 23 of that file).

**What it does not do.** It does not state which open item of the construction file a result answers. A baseline choice is named against the open item it stands in for, because that is what the code did. It is a baseline for the attempt and not an answer to the item. It does not state a goal as the preset. A goal used in an attempt is a goal programmed by hand, and the preset is what may emerge from attempts (§1, item 73 of that file; §2, reading 65).

## 1. Format of an entry

Each attempt is recorded in the following parts, in this order.

1. **The attempt.** The date, the code version, and the aim of the attempt in one sentence.
2. **The baseline choices.** Each choice the code made that the construction file leaves open, the open item it stands in for, and the value used.
3. **The goals used.** The goal given to each side of F, and the goal given to P for the exact check, as they were programmed. Stated as programmed, not as a proposal.
4. **What was run.** The scale, the number of cycles, and what each cycle took as input and gave as output.
5. **What was observed.** Counts and outcomes as recorded by the code, with no reading added.
6. **What was not observed.** What the attempt did not reach, did not measure, or could not run, and why.

A reading of an attempt, if one is made, is recorded as a reading and offered for correction, in the same way as in the construction file.
